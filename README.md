# Outreach Sender

تطبيق بسيط لإرسال إيميلات Outreach لأكتر من شركة، و **Google Sheets هو قاعدة البيانات**:
كل شركة = شيت واحد فيه بيانات الشركة، إعدادات الإيميل المرسل، القوالب، بيانات بورد monday، الداتا، وحالة الإرسال.
الصفحة بتعمل كل حاجة: تجهيز الشيت، الإعدادات، الاستيراد، الإرسال اليدوي والمجدول، ومتابعة الردود.
